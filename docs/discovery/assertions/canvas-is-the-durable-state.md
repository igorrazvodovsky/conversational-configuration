# The canvas is the durable locus of state

The canvas, not the transcript, is the durable locus of state; the chat is for negotiation and explanation.

*Evidence today.* Research threads D and E ([../../research/interaction-literature.md](../../research/interaction-literature.md)), implemented by the [configuration canvas](../../specs/configuration-canvas/requirements.md) and [nonlinear interaction](../../specs/nonlinear-interaction/requirements.md).

*How we would know it is wrong.* Users scroll the transcript to check what was decided, or ask the agent to restate state that is already on screen.

*What rests on it.* The transcript-only surface geometry was set aside because this assertion cannot be exercised under it ([../models/Surface architecture.md](../models/Surface%20architecture.md) §1), and the built repair set is faulted for living in the surface that forgets ([../models/Ripple storyboard.md](../models/Ripple%20storyboard.md) §2).
