# The canvas is the durable locus of state

The canvas, rather than the transcript, is the durable locus of state; the chat is for negotiation and explanation.

*Evidence today.* Research threads D and E ([../../research/interaction-literature.md](../../research/interaction-literature.md)), implemented by the [agreement document](../../specs/agreement-document/requirements.md) and [nonlinear interaction](../../specs/nonlinear-interaction/requirements.md).

*How we would know it is wrong.* Users scroll the transcript to check what was decided, or ask the agent to restate state that is already on screen.

*Status.* The durable half held in the 2026-08-20 walkthrough: a browser reload restored values, forced values, provenance, both drafts with their prices, the priced consideration and the transcript, with nothing re-elicited. What is not durable is the reasoning. The rules behind a deviation, and the reason behind any forced value, exist only in the transcript, which the workspace treats as ephemeral and of which there may be several per agreement. The repair set living in chat is the case already faulted in [Ripple storyboard](../models/Ripple%20storyboard.md) §2; the deviation's missing rules are a second instance of it. The deviation's rules were moved onto the sheet the same day, and the reason behind any unavailable option now travels in state rather than in a conversation. The repair set is still in the transcript, which leaves the storyboard's amendment as the open half.

*What rests on it.* The transcript-only surface geometry was set aside because this assertion cannot be exercised under it ([../models/Surface architecture.md](../models/Surface%20architecture.md) §1), and the built repair set is faulted for living in the surface that forgets ([../models/Ripple storyboard.md](../models/Ripple%20storyboard.md) §2).
