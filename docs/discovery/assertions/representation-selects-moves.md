# The representation of the agreement selects the user's moves

The genre in which the shared artifact is rendered selects which conversational moves users reach for: a parameter sheet pulls toward value-filling and interrogation; a document pulls toward negotiation — objection, correction, redlining. The shared visible object is the deictic ground of the dialogue: people talk about what they can see and point at.

*Evidence today.* Reasoning, plus the adjacent dialogue literature on common ground and deixis; nothing domain-specific, untested here. The claim's transfer from conversation research to a configuration surface is itself an assumption, the same honesty owed as the food-labelling caveat on [two objectives held as a pair](two-objectives-as-a-pair.md).

*How we would know it is wrong.* The walkthrough move mix over the document canvas matches the move mix over the spec sheet; or the document genre suppresses legitimate parameter-level moves the sheet supported — over-selection is failure too.

*What rests on it.* The layered-contract-genre choice in [Canvas anatomy](../models/Canvas%20anatomy.md) §2 — its main argument beyond scale honesty. If this fails, the sheet returns as the primary rendering and the document demotes to an export view. The typed-edits follow-on ([Canvas anatomy](../models/Canvas%20anatomy.md) §4) rests on the stronger form of the claim: that the document can host moves, not merely shape them.
