# The representation of the agreement selects the user's moves

The genre in which the shared artifact is rendered selects which conversational moves users reach for. A parameter sheet pulls toward value-filling and interrogation; a document pulls toward negotiation, meaning objection, correction and redlining. The shared visible object is the deictic ground of the dialogue, since people talk about what they can see and point at.

*Evidence today.* Reasoning, plus the adjacent dialogue literature on common ground and deixis. Nothing domain-specific, and untested here. The claim's transfer from conversation research to a configuration surface is itself an assumption, and needs the same caveat as the food-labelling evidence behind [two objectives held as a pair make the trade-off legible](two-objectives-as-a-pair.md).

*How we would know it is wrong.* The [agreement-document spec](../../specs/agreement-document/requirements.md) built the document canvas, so the test is now runnable and the result is still unknown; one author-run walkthrough cannot produce a move mix. The claim fails if the move mix over the document canvas matches the move mix over the spec sheet. Or the document genre suppresses legitimate parameter-level moves the sheet supported, since over-selection is a failure too.

*What rests on it.* The layered-contract-genre choice in [Canvas anatomy](../models/Canvas%20anatomy.md) §2, which is its main argument beyond scale honesty. If this fails, the sheet returns as the primary rendering and the document demotes to an export view. The typed-edits follow-on ([Canvas anatomy](../models/Canvas%20anatomy.md) §4) rests on the stronger form of the claim, that the document can host moves rather than merely shape them.
