# JTBD notes

Status: *desk-research hypotheses*, grounded in elevator-industry practice — the KONE, Otis and Schindler planning tools and service businesses, and Mitsubishi's M-USE pay-per-use offering as the existing elevator-as-a-service precedent.

Method: plays from the JTBD Playbook set — *Scope the JTBD Domain*, *Expand Market Opportunities*, *Map the Main Job*, *Create Goal-Based Personas*, *Map the Consumption Journey*, and *Align Teams to Job Stories*. Each note names the play it follows.
